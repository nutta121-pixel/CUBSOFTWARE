================================================================
  CUBSOFTWARE SERVER - STARTUP GUIDE
================================================================

PREREQUISITES (install once if not already on the VPS)
-------------------------------------------------------
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt install -y nodejs python3 python3-pip git
sudo npm install -g pm2


STEP 1 — Clone the repo
------------------------
git clone git@github.com:HexEchoTV/CUBSOFTWARE.git ~/cubsoftware
cd ~/cubsoftware/cubsoftware-server


STEP 2 — Set up environment files
-----------------------------------
# Website
cp apps/cubsoftware-website/.env.example apps/cubsoftware-website/.env
nano apps/cubsoftware-website/.env        # fill in all values

# Cub Protector bot
cp apps/cub-protector/.env.example apps/cub-protector/.env
nano apps/cub-protector/.env             # fill in all values


STEP 3 — Install dependencies
-------------------------------
# Bot (Node.js)
cd apps/cub-protector && npm install && cd ../..

# Website (Python)
pip3 install -r apps/cubsoftware-website/requirements.txt


STEP 4 — Create data directory
--------------------------------
sudo mkdir -p /var/cubsoftware-data
sudo chown $USER:$USER /var/cubsoftware-data


STEP 5 — Start with PM2
-------------------------
pm2 start ecosystem.config.js
pm2 save
pm2 startup
# Copy and run the command that pm2 startup prints


================================================================
  DEPLOYING UPDATES (after first setup)
================================================================

On your local machine (or via GitHub Desktop):
  git push origin main

On the VPS:
  cd ~/cubsoftware/cubsoftware-server
  git pull origin main && pm2 restart cubsoftware-website cub-protector


================================================================
  USEFUL PM2 COMMANDS
================================================================

pm2 list                        # show all running processes
pm2 logs cubsoftware-website    # live logs for website
pm2 logs cub-protector          # live logs for bot
pm2 restart cubsoftware-website # restart website only
pm2 restart cub-protector       # restart bot only
pm2 restart all                 # restart everything
