Modmail

Private support system via DMs

How Modmail Works

1. Send a panel to a channel with a "Contact Modmail" button
2. Users click the button to open a private modmail thread
3. The bot DMs the user and creates a staff-only channel
4. User replies via DM, staff replies in the modmail channel
5. All messages are relayed between the user and staff

Custom Bot

Run all CUB PROTECTOR features under your own Discord bot's name and avatar

How to set up your custom bot

  1. Go to discord.com/developers/applications and click New Application
  2. Go to the Bot tab, enable Privileged Gateway Intents (Presence, Server Members, Message Content)
  3. Under Token, click Reset Token, copy it, and paste it below
  4. Click Activate Custom Bot — your bot starts automatically and the invite page opens
