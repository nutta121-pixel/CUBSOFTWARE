Built for Every Server

From small communities to large servers — every feature you need, right out of the box.

Temp Voice Channels

Users join a hub and instantly get their own private channel. Full owner controls — lock, hide, permit, ban, rename, set limit, transfer ownership, and choose bitrate.

Moderation Suite

Ban, kick, mute, warn, timeout, softban, purge, lockdown, slowmode. Full case history, user notes, auto-punishment escalation, mod logs, and ban appeals with a public web form.

Auto-Moderation

Bad words, spam, invite links, caps abuse, mass mentions, duplicate text, excessive emojis — all configurable with per-filter actions, thresholds, and role exemptions.

Event Logging

Log message edits and deletes, joins and leaves, bans, voice activity, role changes, name changes, emoji usage, channel activity, boost events, and more — all to separate channels.

Leveling & XP

Message and voice XP, level-up announcements, role rewards at milestones, leaderboards, custom XP multipliers, and per-channel XP boosts. Fully configurable.

Economy

Custom server currency, daily/weekly rewards, a fully stocked server shop, item purchases with role grants, balance management, and achievement rewards.

User Profiles & Moods

Members set a bio, embed color, and custom links on their profile card. Set a mood emoji and status message displayed on their profile. View anyone's profile with /profile view.

Rep & Relationships

Give reputation points to other members. Propose marriage or send friend requests — accepted via Discord buttons. All visible on the web dashboard with a leaderboard.

Tournaments

Create bracket-style tournaments from the dashboard or with /tournament create. Members join, then start the bracket and record match results. Single-elimination format with auto-bracket generation.

Debate Mode

Lock any channel to two designated debaters — all other messages are automatically deleted. Debates auto-end after 30 minutes. Set an optional log channel to archive debate summaries.

Content Feeds

Auto-post from Reddit subreddits (hot/new/top) and RSS news feeds to any channel. Schedule a daily Meme of the Day and Quote of the Day — all configured from the dashboard.

Reaction & Self Roles

Button, reaction, and dropdown role menus. Self-assign preset or custom categories (Star Signs, Pronouns, Gaming, etc.). Color roles so members can pick their own username colour.
