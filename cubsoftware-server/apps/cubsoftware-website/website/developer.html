Meme API
GET /api/memes/{category} Fetch a random meme

Returns a random meme from the specified category. Results are always SFW and non-spoiler filtered.

ParameterTypeRequiredDescription
category string optional Meme category (see list below). Defaults to random if omitted.

"author":   "CUBSOFTWARE"

Discord Bot Examples

Drop-in examples for adding a /meme slash command to your Discord bot using the CUB SOFTWARE API. Each example registers the command and sends the image — copy, paste, add your token.

// npm install discord.js const { Client, GatewayIntentBits, SlashCommandBuilder, EmbedBuilder } = require('discord.js'); const client = new Client({ intents: [GatewayIntentBits.Guilds] }); client.once('ready', async () => { await client.application.commands.create( new SlashCommandBuilder() .setName('meme') .setDescription('Get a random meme') .addStringOption(o => o .setName('category') .setDescription('Meme category (optional)') .setRequired(false)) ); console.log('Ready!'); }); client.on('interactionCreate', async interaction => { if (!interaction.isChatInputCommand() || interaction.commandName !== 'meme') return; await interaction.deferReply(); const category = interaction.options.getString('category') || 'random'; const res = await fetch(`https://cubsoftware.site/api/memes/${category}`); const meme = await res.json(); if (meme.type === 'text') { const embed = new EmbedBuilder() .setTitle(meme.title) .setDescription(meme.text) .setColor(0x5865F2); return interaction.editReply({ embeds: [embed] }); } const embed = new EmbedBuilder() .setImage(meme.url) .setColor(0x5865F2); return interaction.editReply({ embeds: [embed] }); }); client.login('YOUR_BOT_TOKEN');

Want /meme dank, /meme cat etc. as separate subcommands?

Instead of a string option, register each category as its own subcommand. Replace the command registration in the examples above with the snippet below, then read getSubcommand() / interaction.data.options[0].name in your handler instead of getString('category').
