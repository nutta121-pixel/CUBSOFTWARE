About CUB SOFTWARE

CubSoftware is an independent software development project focused on creating tools, platforms, and automation designed to help online communities run more smoothly.

CubSoftware was founded and is owned by CUB, a developer from New Zealand. What started as a personal development project has grown into a small team effort, with three developers working together to build and maintain the CubSoftware ecosystem.

The goal behind CubSoftware is simple: build useful tools that communities can rely on without putting them behind paywalls. All CubSoftware projects are completely free to use, and the team is committed to keeping them that way. The philosophy is that powerful tools for managing communities and building online spaces should be accessible to everyone, not just those who can afford subscriptions or premium features.

Most CubSoftware projects focus on improving community platforms, particularly through:

  • Discord bots and automation tools
  • Community management utilities
  • Web platforms connected to online communities
  • Experimental and developer-driven software projects

The team works on these projects independently, continually experimenting with new ideas and improving existing tools based on community feedback. CubSoftware isn't a large corporation — it's a developer-driven project built by people who enjoy creating useful software for others.

As the ecosystem grows, the focus remains the same: create reliable tools that help communities run better, while keeping everything free and accessible to everyone.

CUB SOFTWARE Offers 30+ Free Browser-Based Tools With No Account Required

CUB SOFTWARE, built and maintained by a small independent team of developers, provides a comprehensive suite of free online tools accessible to anyone with a browser. Covering media downloads, file conversion, document generation, image editing, Discord utilities, and live-streaming overlays, the platform removes every barrier between users and useful software — no sign-up, no paywall, no ads.

The platform also includes two Discord bots: CUB PROTECTOR, a moderation and server security bot, and CleanMe, which allows Discord communities to share and copy server setups instantly. Both bots are free and managed through dedicated web dashboards.

Stream Overlays, a newer addition, lets content creators build browser-source overlays for OBS directly from their browser — with Twitch alert integration and live customization.
