👤 User Info
$(user)Display name of the user who triggered the commandCubSoftware
$(nick)IRC lowercase usernamecubsoftware
$(userid)Twitch user ID number123456789
$(touser)First argument stripped of @, or the sender if no args givenFriend
$(color)User's chosen chat colour (hex code)#FF4500
$(ismod)Returns 1 if the user is a Moderator or above, else 01
$(isvip)Returns 1 if the user is a VIP or above, else 00
$(issub)Returns 1 if the user is a Subscriber or above, else 01
✏️ Input & Arguments
$(query)Everything typed after the command namehello world
$(args 1)First word of input. Change number for 2nd, 3rd, etc.hello
🔢 Counters
$(count)How many times this command has been used in total. Increments on every use.42
$(usercount)How many times this specific user has used this command7
🎲 Random & Logic
$(random 1 100)Random integer between two numbers (inclusive)73
$(choose a|b|c)Pick one of the pipe-separated options at randomb
$(math 1+2)Evaluate a math expression. Supports + - * / ** % //3
$(if cond|yes|no)Return the second value if condition is truthy (non-empty, non-zero), else the thirdyes
🔤 String Manipulation
$(upper text)Convert text to UPPERCASE. Can wrap other variables, e.g. $(upper $(game))TEXT
$(lower text)Convert text to lowercasetext
$(length text)Number of characters in the text4
$(repeat text|N)Repeat text N times (max 20). Separate text and count with a pipe.texttexttext
